# University-Management-System-with-MySQL
A console-based University Management System developed using C++, OOP concepts, and MySQL database connectivity.
This project allows users to insert, view, search, update, and delete student records stored in a MySQL database.

Features-
Insert student records
Display all student records
Search student by ID
Update student subject
Delete student record
Secure MySQL database connection
Object-Oriented Programming (OOP) design

Technologies Used-
Programming Language: C++
Database: MySQL
Libraries / Tools:
MySQL Connector/C
<mysql.h>
<windows.h>
<sstream>
IDE: Visual Studio Code
Platform: Windows

Concepts Applied-
Object-Oriented Programming (Classes & Objects)
Encapsulation (Getters & Setters)
MySQL Database Connectivity
CRUD Operations
String Streams
Menu-driven program
Error handling
